## Tentang

GoTrick adalah permainan sulap berbasis kartu di mana pemain memilih sebuah kartu dan aplikasi akan menebaknya melalui trik matematika klasik. Sederhana, seru, dan bikin takjub.

## Fitur

- Trik sulap tebak kartu klasik
- Tampilan dark & light mode
- Ringan dan cepat
