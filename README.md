## About

GoTrick is a card-based magic trick game where the player picks a card and the app reveals it through a classic mathematical trick. Simple, fun, and surprisingly impressive.

## Features

- Classic card guessing magic trick
- Beautiful dark & light mode support
- Lightweight and fast
